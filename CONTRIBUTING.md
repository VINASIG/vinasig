# Contribute

Read AGENTS.md and the product brief before changes. Preserve unrelated work, the static default and the pinned assets. Review project metadata against its actual source before adding it to the inventory.

Run the strict source checks, inventory tests and static build. Visible changes also need the relevant Playwright matrix, opened screenshots and actual keyboard/touch checks. Performance changes need comparable before/after lab evidence. Keep captures and local logs in ignored output/ and record durable findings in docs/audits/.

Commit, push and deployment follow the maintainer's current authorization. Do not introduce a source/artwork license, analytics, account requirement or custom-domain migration as an incidental change. Report unrun checks and observed limitations honestly.
