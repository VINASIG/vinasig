# Product brief

The website gives visitors a clear entry point into VINASIG projects. The owner authorized implementation, standardization, public GitHub publication and deployment on 3 October 2026. That current instruction authorizes work on this repository and supersedes the older instruction to reserve it for a future website.

## Audience and tasks

- Open a practical browser tool without creating an account.
- Understand what a tool does before navigating to it.
- Find the actual source, shared standards and organization contact directory.
- Understand VINASIG and its use of SI agents without unsupported capability claims.

The four deployed tools and four public foundation repositories were verified against the organization inventory. BMI Calculator leads the tool list because it is the latest completed project and addresses the owner's stated military-service priority. Medical and legal interpretation stays in that tool and is not duplicated on this website.

## Interface

English and Vietnamese homepages contain a measured hero, four tool articles, a compact list of foundation resources, organization information and three native disclosures. Each tool has separately named website and source links. The header keeps all destinations visible and wraps naturally on narrow screens. There is no hover-only navigation, mobile drawer, search, filter or modal needed for an eight-entry inventory.

The generated 404 page shares identity, navigation and footer, has a working homepage return link, and is excluded from indexing. The owner authorized a custom-domain migration on 4 October 2026. GitHub Pages publishes the site at https://vinasig.io.vn/ with an origin-root base. See DOMAIN.md and DOMAINS.md for configuration and verification.

## Privacy and delivery

The website requires no JavaScript for content or interactions. It makes no runtime repository API calls and sets no cookies or web storage. Page hosting receives ordinary HTTP requests. Visitors navigate to external project and GitHub destinations through real links. No messages are sent to others and no visitor measurement is collected.

## Acceptance

Run source, inventory, generated HTML, preserved asset, browser and lab performance checks. Inspect real screenshots and interaction states for the homepage and custom 404. Verify the exact pushed commit, required CI, Pages deployment and public resources before reporting publication complete. Physical-device and screen-reader use, field metrics, ranking, fresh Codex discovery and an independent SI-agent trial require their own observed evidence.
